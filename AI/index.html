Tutorialhow to build a working chat bot in ~5 minutes

1

Run a finished bot first

A full example is already loaded ("Nova"). Hit Test top-right and click through it — type "human" or an order number like ORD-1024. See how every reply maps to a node on the canvas.

2

Start your own

Hamburger menu → New blank bot. You get a single Start node. The flow always begins there, and it always runs from Start when you press Test.

3

Drop nodes

In the left palette click a type, then click the canvas to place it. Message says something. Question asks and routes. Action fires a webhook/email (automation). End stops the bot.

4

Connect them

Drag the green dot on a node's right edge onto another node. For Question nodes, each line you draw becomes an option button or a keyword route.

5

Edit a node

Click a node → edit in the right Inspector: label, the message it says, options/keywords, webhook URL. Message nodes have a Next step dropdown there too. Click an arrow line on the canvas to rename a route.

6

Make it smart

In Settings, paste a short Knowledge base about your business. Any free-text reply your rules miss is answered by the free AI brain (cloud AI with an on-device fallback). The AI write button in the inspector writes message copy for you.

7

Keep it in a loop

Every chain should end at End, or loop back to your main menu Question (drag a line back to it) so the chat never dies.

8

Save and share

Everything autosaves in this browser. Use Export JSON to download your flow, and Import to load one later or on another computer. Need another starting point? Hamburger menu → Load example: Pizza Bandit — an order-taking bot with a loop.
