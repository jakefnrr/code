TERMINAL REFERENCE

Project commands

This simulated terminal works with files inside the active NEXUSIDE project. It cannot access your computer’s system files or run arbitrary system programs.

pwd · ls · cd · cd ..Show the current project location, list items, or move around folders.
mkdir · touch · rm -rCreate folders and files or remove project items.
cat · head · tail · wcRead file contents and get basic file counts.
open · vi · nanoOpen a file in the built-in editor; vi/nano create it if needed.
