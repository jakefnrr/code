GreenChat

A modern, real-time messaging platform with a sleek dark aesthetic — search a username, send a friend request, manage groups, and chat instantly across the world.

>
Friends — find people by username and send friend requests
>
Groups — create group chats and add members
>
Real-time — messages and notifications push live
>
Private — row-level security keeps your data yours
